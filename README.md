# Local Steals & Deals

## Project Overview
Local Steals & Deals is a client-side e-commerce web application developed using HTML, CSS, and JavaScript.

## Features
- User Registration
- User Login
- Product Dashboard
- Product Search
- Category Filtering
- Product Details Page
- Shopping Cart
- Checkout System
- Responsive Design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage
- Fake Store API

## Installation Guide
1. Download project files
2. Open in VS Code
3. Run with Live Server
4. Register a new account
5. Login and start shopping

## Test Credentials
Create your own account through registration page.
